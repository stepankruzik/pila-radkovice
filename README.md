# Pila Radkovice – Webová prezentace

Moderní a responzivní webová prezentace historické pily v Radkovicích u Budče (založeno 1850). Projekt klade důraz na propojení poctivé tradice zpracování dřeva s moderními technologiemi.

## 🌲 O projektu
Web slouží jako informační portál pro zákazníky pily. Obsahuje informace o historii areálu, ceník služeb (pořez a výkup kulatiny), galerii rekonstrukce a kontaktní formulář.

## ✨ Hlavní funkce
- **Responzivní design:** Web vypadá skvěle na desktopech, tabletech i mobilních telefonech.
- **Interaktivní karusel:** Hlavní slideshow na úvodní stránce s plynulými přechody.
- **Galerie s Lightboxem:** Sekce historie obsahuje zvětšovací galerii fotografií z rekonstrukce areálu (2015–2022).
- **Poptávkový formulář:** Integrovaný mailto skript pro rychlé odeslání poptávky jednateli.
- **Dynamická mapa:** Vložená mapa pro snadnou navigaci do areálu.

## 🛠 Použité technologie
- **HTML5:** Sémantická struktura stránek.
- **CSS3:** Vlastní design s využitím Flexboxu, Gridu a CSS proměnných pro snadnou údržbu barev.
- **JavaScript:** Logika karuselů, lightbox galerie a automatické generování roku v patičce.
- **Google Fonts:** Využití písem *Cinzel*, *Montserrat* a *Playfair Display* pro dosažení prémiového historického vzhledu.
